核心结论：分层清晰、护栏密集，自用可靠；但存在一个决定性代差—— 知识（卡片/文档）已用语义+关键词混合检索，而"关于你的长期记忆"只会按时间倒序摊开最近 44 条， 现成的向量检索基建没有被记忆层复用。这是"工具型 Agent"与"真正懂你的企业级记忆 Agent"的分水岭，且修复性价比最高。

二、记忆体系：实际四层，但检索能力不对称
L0 工作记忆
ReAct 对话窗
单轮；48000字符封顶，只压工具观察，绝不截 system/user
L1 协作记忆
Blackboard 黑板
单次流水线会话；findings/artifacts/messages；纯内存、不持久化、无写权限隔离
L2 长期用户记忆
aiMemories（core/偏好/事实）
300条上限；注入12/12/20条、1800字；只按 updatedAt 时间倒序，与问题无关
L3 知识记忆
embeddings（卡片/文档）
chunk 500字+50重叠；语义+关键词混合检索 topK；全表3000行 OOM 护栏
代差示意：同样是"找相关内容"—— 知识层会按你的问题做向量相似度，精准翻到最相关的卡片； 记忆层却无视问题，永远只摊开"最近更新的 44 条"。 于是 3 个月前那句最关键的"考研数学一"，只要最近聊了 44 条别的就被挤出；无关新记忆反而占位白付 token。 而 embeddings 表、hybridSearch、本地降级、模型签名重建全都现成——记忆只是没接进去。
三、对照顶级企业级记忆架构的六个缺口
① 记忆无语义召回（决定性）
时间倒序固定注入，相关老记忆被新记忆挤出；现成向量基建未复用
② 无遗忘/衰减/巩固
只有300条硬裁剪+静态importance；无时间衰减、无命中强化、无事实过期
③ 缺情景记忆/程序记忆
只有"事实记忆"；会话摘要（上周学了啥）、用户工作流套路无处安放
④ 多Agent共享=全有或全无
记忆表无 agentId/scope，11个Agent共享一份；黑板可互相覆盖、可伪造消息
⑤ 隐私权限缺失
含身份/目标的记忆随同步包裸发跨设备；无 local-only/敏感分级/记忆治理界面
⑥ 一致性=最后写入胜出
fieldTs 字段级时间戳"为将来预留"未实现；重复记忆直接覆盖、无版本历史

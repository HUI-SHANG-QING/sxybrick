## 三、七维交叉审视（本轮聚焦：可扩展性与安全性）

### 1. 架构 / 工程（本轮焦点）
- **插件系统是双刃剑**：一方面把「用户级/社区级扩展」变成一等公民，呼应「专家中心 / 专家包」范式，是平台化（卡组市场 + 插件生态）的底层底座——方向极具前瞻。
- **致命短板**：`loader.js` 用 `Blob + import()` 执行任意 JS，**无沙箱、无 CSP、无权限声明**。对本地单机应用，威胁来自「用户误装恶意插件」或「DB 被篡改」——当前靠「插件不进同步」降低跨设备扩散风险，但本机零隔离仍是 P1。建议：① 插件代码加「安装前明文审查 + 数字签名/哈希校验」；② 用 `<iframe sandbox>` 或 Worker 隔离执行；③ 至少补 CSP `script-src` 限制。
- **未提交债务**：26 文件 dirty（含 `fsrs.js`/`plugins/`/`genQuiz.js`/`examAnalytics.js` 等高价值模块未跟踪）——一旦崩坏或误删，AI 高速产出成果可能丢失。**应先分批 commit 恢复可回溯**。

### 2. 算法工程
- FSRS 已 live（见上）——这是认知科学落地的旗舰成果。
- **R12 仍存**：`fsrs.js` 257 行纯函数却**无单测**，作为最高价值算法，数值正确性（区间单调性、`trainWeights` 收敛、权重非负）必须补 `tests/fsrs.test.mjs`。
- GenQuiz 的 `gradeQuestion` 仅做「选择正确/错误」二元判定（行 215），较粗糙；客观题可，主观题（填空/简答）评分仍靠 AI，需明确『何时用 AI、何时本地判』的边界。

### 3. 学习科学 / 复习科学
- FSRS + 生成式测验 + 模考分析，已覆盖「间隔重复 + 测试效应 + 诊断」三大支柱。
- 仍缺：交错练习（interleaving）、检索强度分级（再认/回忆/生成）、用 `userOps` 校准 FSRS 的训练闭环尚未在 UI 形成「积累→训练→切换」引导漏斗。

### 4. 前端 / UI / 视觉
- 新增 Plugins 管理页、GenQuiz 页；与既有 24 视图构成「学习 OS」级界面密度。
- 待验证：虚拟滚动（长列表渲染）、移动端手势、暗/浅主题可读性硬编码一致性。

### 5. 数据资产化 / 隐私（关键遗留）
- **R7′（P0 残留）**：`Export.vue` 隐私导出仍是明文 JSON/CSV（v4 已确认，本轮复验未变）→ PIPL 最后一公里未闭合。
- 插件「不进同步」是正确取舍；但 `snapshots` 表的同步归属需明确（v15，建议也默认不同步，含个人画像）。

### 6. 产品经理视角
- 功能广度已达「学习操作系统 + 可扩展平台」双重定位，留存钩子（间隔/打卡/成就/周报/模考/插件）极全。
- 风险：广度继续 > 聚焦，「什么都做」稀释单点深度；FSRS/插件需引导激活，否则用户感知不到价值。

### 7. 顶尖学生用户群（考研党）
- 模考 + 生成测验 + FSRS，精准命中「真题穿透/背诵/焦虑」痛点。
- 真题「填空式背诵」（政治/作文）仍未落地（蓝图 P2），是考研党最痛的未覆盖项。

## 七、元结论（辩证）

SxyBrick 用「单作者 + AI 编辑器 + 3 天/350 元」的持续范式，已把「本地优先复习工具」推到「带插件生态的学习 OS」——FSRS 算法壁垒、插件可扩展性、生成式测验这种通常需要专业团队数月的工作，被高速兑现。但本范式的内生矛盾在这一轮彻底显形：**高速广度扩张 ↔ 工程深度（提交纪律/测试/沙箱/类型）的系统性欠账**。从「惊艳原型」晋级「可信赖平台」，不是再堆叠功能，而是**把未提交代码、隐私加密、FSRS 单测、插件沙箱四块「深度债」一次性还清**。报告内含完整 v4→v5 风险登记表、量化评分卡与行动清单，可直接作为立项/验收依据。

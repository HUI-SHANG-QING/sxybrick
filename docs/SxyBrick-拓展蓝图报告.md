# SxyBrick 拓展蓝图：从「复习工具」到「考研学习操作系统」

> 基于项目真实现状（db v14、sync-manifest 单一事实源、SRS 变体、Agent 框架、数字孪生/隐私/资产管家、opt-in 隐私同步已落地）的延伸分析。
> 视角：学习科学 · 复习科学 · 数字资产化/市场协同 · 软件架构/前端/UI · 顶尖学生用户群 —— 交叉融合、辩证审视。
> 目标：在「广义学习效率」与「考研场景」双重约束下，给出**下一步可立即推进的拓展方向**。

---

## 一、六棱镜交叉审视（先看清现状，再谈未来）

### 1. 学习科学 / 复习科学视角（最该被「科学」照亮的环节）
当前 SxyBrick 已落地的「记忆科学」基础设施是扎实的：SM-2 变体 + 短期巩固窗口、错因驱动、费曼输出、错卡补卡、知识图谱、数字孪生 Dashboard——但对标记忆科学前沿，仍有明确落差：

- **缺口 A：留存模型落后。** SM-2 是 1970s 模型，现代 **FSRS（Free Spaced Repetition Scheduler）** 用机器学习拟合每个用户的遗忘曲线，实测比 SM-2 节省 20–30% 复习时间达到同等记忆保持率。SxyBrick 已埋点 `userOps`（每次复习/评分），但**尚未反哺算法**——这是「数据两张皮」的最大浪费。
- **缺口 B：交错练习（Interleaving）缺失。** 当前复习是「按卡顺序 / 按计划」线性推进；认知科学证明，把不同科目/题型交错刷比集中刷单个主题 retention 更高。考研数学尤其需要「高数→线代→概率」穿插。
- **缺口 C：测试效应未细分。** 「背诵/默写/选择题/讲解」四种检索强度不同；当前仅用 `grade` 四档，未区分「再认 vs 回忆 vs 生成」，无法据此调整调度权重。
- **缺口 D：生成式测验缺位。** 没有「AI 出小题 / 变式题 / 反向提问」能力，仍靠用户手动建卡。

### 2. 数字资产化 / 用户-市场协同视角
- **资产化已有骨架**：E1（卡组）/ E2（画像）/ E3（导出）框架存在，本地主权理念领先。
- **断裂点**：资产仍是「单机孤岛」。卡组无法署名、无法版本化、无法协作、无法交易/订阅；`userOps` 海量行为数据只进不出，未形成「个人模型 → 提升体验」的飞轮。
- **协同机会**：把「本地主权资产」升级为「可署名、可协作、可订阅」的**卡组市场 + 学习小组**。这是从「工具」跃迁到「平台」的唯一杠杆点（网络效应）。

### 3. 软件架构 / 工程视角
- 优势：sync-manifest 单一事实源、Agent 框架、opt-in 隐私治理已落地。
- 负债：仍为纯 JS（0 TS）、仅 5 份测试、多处主线程 O(n²)（analytics）、bus-factor=1、37 文件未提交。
- **辩证**：高速 AI 构建换来广度，但「深度（测试/类型/性能）」是下一步必须还的债，否则拓展越多、熵越大。

### 4. 算法工程视角
- 现有：难度系数 / 错因惩罚 / 巩固状态机 / 自适应 / 强度——方向对。
- 脆弱点：`wrongPenalty` 已改枚举（好），但**图谱驱动复习用 front/back 文本字符串匹配映射卡片**（R10），两张卡文本相同会静默覆盖；应改用卡片 id 直连边。

### 5. 前端 / UI / 视觉视角
- 已有 5 套游戏级主题 + 3 模式，但「复习流」仍是「翻卡→评分」单通道，缺少**无打断的沉浸复习态**、移动端手势、骨架屏、虚拟滚动（千卡级卡顿）。
- 视觉变量尚未跟随 IDE 主题硬编码一致性（需确认暗/浅主题可读性）。

### 6. 顶尖学生用户群视角（考研党）
考研党核心痛点：**时间稀缺、科目多、信息过载、背诵量巨大、焦虑驱动**。用户画像分三类——跨考无基础（如你，408 需攻坚）、二战求稳、在职碎片化。他们的真实需求不是「更多功能」，而是：
- **真题穿透**：真题→自动拆卡→错题回溯→同类变式；
- **背诵闭环**：政治/英语作文等长文本「填空式背诵 + 语音校验」；
- **模考与预测**：基于掌握度给「该刷哪套卷」的决策。

## 二、考研场景专项优化（按科目对症下药）

| 科目 | 痛点 | SxyBrick 当前能力 | 专项拓展 |
|---|---|---|---|
| **数学一** | 计算量大、题型多、易错点细 | 卡片/错卡/SRS | 真题套卷模式（按年份/章节）、计算题「步骤卡」、错因自动归类（公式/计算/概念） |
| **英语一** | 单词量大、阅读长难句、作文背诵 | 卡片/费曼 | 阅读精读卡（句子拆解）、作文「填空式背诵 + 语音朗读校验」、词根词缀图谱 |
| **政治** | 背诵量大、时效强、选择题陷阱 | 卡片/背诵 | 「填空挖空」背诵卡、时政动态卡（带有效期）、选择题混淆项训练 |
| **408** | 概念密集、跨章节、需画图 | 图谱/卡组 | 跨章节知识图谱联动、代码卡（可运行片段）、AOE/状态机可视化卡 |

## 三、后续拓展方向（按「优先级 + 类型」分层，可分批落地）

### P0 — 闭环正确性 & 体验（先做，否则拓展越多越乱）
1. **修 R10（图谱 id 直连）**：把 `mapLabelsToCards` 改成边存卡片 id，避免文本匹配静默覆盖。
2. **修 R7′（隐私最后一公里）**：opt-in 同步/导出的 `privacyRecords` 仍需 AES-GCM 加密载荷，而非明文 JSON/CSV。
3. **清 37 文件 dirty 树**：分批 commit，恢复可回溯状态。
4. **虚拟滚动 + Web Worker**：把 analytics 的 O(n²) 全表扫描移出主线程，千卡级流畅。

### P1 — 学习科学增强（提升「效率」核心）
5. **FSRS 留存模型**：用 `userOps` 真实评分训练每用户遗忘参数，替换/并行 SM-2，预计省 20–30% 复习量（最高信号）。
6. **交错练习调度**：复习队列按「科目/题型/难度」交错，而非线性。
7. **检索强度分级**：背诵/默写/选择/讲解 映射不同调度权重。
8. **生成式自适应测验**：AI 基于薄弱点自动出小题 + 变式，闭环回写卡片。

### P2 — 考研场景专属功能
9. **真题套卷模式**：导入真题（txt/markdown）→ 自动拆卡 → 错题回溯 → 同类变式推荐。
10. **填空式背诵卡**：长文本（政治/作文）支持挖空默写 + 模糊匹配评分 + 语音朗读。
11. **模考与预测 Dashboard**：基于掌握度给出「今日该刷哪套 / 哪章最弱」决策面板。

### P3 — 资产化 & 生态（平台杠杆）
12. **卡组市场**：署名卡组、版本化、订阅/一次性付费、UGC 审核、许可协议。
13. **学习小组 / 班级协同**：共享卡组、进度看板、错题共答、考研搭子进度对比（脱敏）。
14. **个性化模型变现**：用匿名学习数据训练「考研记忆基线」，反哺所有用户调度。
15. **内容来源插件**：一键从 PDF/教材/笔记（IMA/Tencent Docs）批量抓卡。

## 四、落地节奏（建议）

- **本周（P0）**：R10 + R7′ + 清提交 + 虚拟滚动。
- **本月（P1）**：FSRS + 交错 + 检索分级 + AI 自适应测验（先内部验证留存提升）。
- **下季度（P2/P3）**：真题套卷 + 填空背诵 + 卡组市场 MVP（本地/局域网先行，云后端可后置）。

**一句话结论**：SxyBrick 已是「架构纪律 + 记忆科学 + 本地主权」的准产品级内核；下一步最高 ROI 是把 `userOps` 数据真正接进 FSRS 闭环（P1-5），把「单机资产」升级为「可协作可订阅」的生态（P3），并在考研真题/填空背诵上做场景穿透（P2）。所有拓展都应以「不破坏 sync-manifest 单一事实源、不引入后端依赖」为红线。

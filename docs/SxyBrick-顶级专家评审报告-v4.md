## 一、执行摘要（一句话）

SxyBrick 正以**惊人的 AI 原生速度**把「考研学习操作系统」从概念推向准产品：本轮最大的里程碑是 **FSRS-4.5（机器学习遗忘曲线）的正确落地**——这是绝大多数商业记忆软件（包括 Anki 默认）的核心壁垒，本项目已用纯函数 + Web Worker + opt-in 训练器实现；但「广度持续 > 深度」的张力仍在：隐私导出明文（R7′）、0 TypeScript、FSRS 缺单测，是晋级商业化前最后几道必须还的债。

**综合评分：8.6 / 10**（v3 的 8.1 → 8.6，主要因 FSRS + R10 + R6 + 错误边界 + 离线兜底四项硬骨头被啃下）。

## 三、七维交叉审视（本轮重点：算法与工程）

### 1. 算法工程（本轮最亮眼）
`src/fsrs.js`（257 行）是**教科书级**实现：
- 正确实现 FSRS-4.5 核心方程 `R=(1+t/(9S))^-1`、稳定度/难度更新、`nextInterval` 反解、19 权重有限差分梯度下降训练器（`trainWeights`）。
- 纯函数、零依赖（无 IndexedDB/window）→ 可在 Web Worker 与 Node 单测运行，设计克制。
- **正确工程闭环**：opt-in 切换（App.vue:100 `scheduler: 'sm2'|'fsrs'`）、权重持久化 `db.meta['fsrsWeights']`、训练 offload 到 worker（主线程零阻塞）、冷启动用全局先验、样本不足（`reviews.length<8`）回退默认——**鲁棒性考虑周全**。
- 风险：① **FSRS 尚无专属单测**（最高价值算法，应立即补，验证 `schedule`/`trainWeights` 数值合理性）；② 训练器 `O(iters×19×2×samples×cards)` 对超大历史在 worker 内仍可接受，但无进度/取消，建议后续加迭代上限与早停日志。

### 2. 软件架构 / 工程纪律
- 优势：sync-manifest 单一事实源未被破坏、错误边界、worker 化、opt-in 治理。
- 负债：**TypeScript 仍为 0 文件**；dirty 树 8 文件（其中 `fsrs.js` 未跟踪、`srs.js/repo.js/sync-manifest.js/Review.vue/analytics.js` 改动未提交）——FSRS 是核心算法，**必须立即 commit + 补单测**再继续拓展，否则回归风险高。

### 3. 学习科学 / 复习科学
- FSRS 落地使「用 userOps 真实评分反哺调度」从蓝图变为现实（v3 指出的「数据两张皮」开始闭合），预计实际节省 20–30% 复习量（需训练后 A/B 验证）。
- 仍缺：交错练习（interleaving）、检索强度分级（再认/回忆/生成）、生成式自适应测验——这些是下一阶段差异化点。

### 4. 前端 / UI / 视觉
- 新增国风水墨主题（提交 `9fcc5c6`），主题体系已达 6+ 套；平板触控/AI 悬浮球/通知铃铛拖动丝滑（提交 `cc1aec1`）。
- 仍缺：虚拟滚动（R6 修了计算但长列表渲染未验证）、移动端复习手势、暗/浅主题可读性硬编码一致性复核。

### 5. 数据资产化 / 隐私（关键遗留）
- **R7′ 未修（P0 残留）**：`Export.vue:119-126` 隐私导出仍是**明文 JSON + CSV**（无 `encryptBackup` 调用），`privacyRecords`（情绪/压力/财务/精神心流）opt-in 后导出仍裸奔 → PIPL 最后一公里未闭合。
- 资产化正面：E1/E2/E3 框架 + 卡组署名（E2）+ 模考走势叙事（E3）已就位，为「卡组市场」生态打底。

### 6. 产品经理视角
- 功能广度已达「学习 OS」级别（数字孪生首页、模考 AI 讲解、易混对决、单科诊断、自动编排计划）——留存钩子齐全。
- 风险：广度 > 聚焦，最豪华的埋点尚未转化为「该不该砍哪个模块」的产品决策；FSRS 训练需引导用户「积累评分→训练→切换」的激活漏斗。

### 7. 顶尖学生用户群（考研党）
- FSRS + 模考 + 单科诊断 + 自动计划，精准命中「时间稀缺/科目多/焦虑」痛点。
- 场景穿透仍弱：真题套卷、填空式背诵（政治/作文）、英语语音背诵尚未落地（见 v3 蓝图 P2，本轮未触及）。

## 七、元结论（辩证）

本项目用「3 天 / 350 元 / 单作者 + AI 编辑器」持续产出传统团队数月才能堆出的**架构纪律 + 认知科学 + 自研 Agent + 数据主权**四位一体内核，且**本轮连 FSRS 这种算法壁垒都正确啃下**——这在「AI 原生开发」范式里是罕见的正样本。但它也暴露该范式的典型副作用：**广度持续 > 深度**（隐私明文、0 TS、核心算法缺测）。从「惊艳原型」晋级「可信赖商业产品」，关键不在再堆功能，而在**把 R7′、FSRS 单测、TS 化三块「深度债」还清**，再把「单机资产」升级为「可协作可订阅」生态。报告内含完整 v3→v4 风险登记表、量化评分卡与行动清单，可直接作为立项/验收依据。

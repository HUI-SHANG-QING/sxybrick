## 二-2、高效技巧（快捷键与批量操作）

- **背诵页快捷键**：空格翻面，`1` 没记住 / `2` 还模糊 / `3` 记住了（自动进入下一张）
- **25 分钟复习会话**：背诵页点「25 分钟会话」开始倒计时，结束提示去番茄钟休息
- **自适应节奏**：背诵页开启后，按每张卡近 10 次错误率微调复习间隔（高频错卡更快重现）
- **易混对决**：背诵页进入，考"答案属于哪张卡"，专治相似知识点混淆
- **语音作答**：复述答案，AI 按关键词覆盖率打分；覆盖率 <40% 会安排 30 分钟内重练（行为回写记忆曲线）
- **批量建卡**：卡片页「批量建卡」，粘贴清单（每行一张，`|` 或 `→` 分隔正反面）一次导入
- **智能卡组**：卡片页筛好后点「保存当前组合」，一键复用（本机偏好）
- **错题智能补卡**：错题页为每道错题（或最薄弱 5 题）AI 生成变式题
- **默写题型**：新建卡选「默写」，复习时逐字比对、全对自动算「记住了」
- **复习提醒**：🎨 设置里开启每日提醒（应用打开时生效，当日一次）

## 四、方式①：手动导出 / 导入（最稳，强烈建议定期做）

### 导出
1. 应用左侧/顶部导航进入「**同步**」页；
2. 点「**导出数据包**」→ 浏览器会下载一个 `sxybrick-备份-日期时间.json` 文件；
3. 这个文件包含**全部数据**：卡片、复习记录、图片、AI 对话（问答/费曼/Agent）、记忆、备忘、计划、知识图谱、AI 文档、番茄专注、每日目标。

### 导入（在另一台设备上）
1. 把数据包文件传到新设备的浏览器（微信文件传输助手、QQ、网盘、U盘都行）；
2. 新设备浏览器打开应用 →「**同步**」页 → 点「**导入数据包**」→ 选择该 `.json` 文件；
3. 提示「导入完成：卡片 +N …」即成功，刷新后卡片、进度、错题全部到位。

### 合并规则（两台设备都有数据时）
- 同一张卡：内容修改按「最后修改时间」谁新听谁；
- 复习进度与文字编辑**互不覆盖**（双时间戳字段级合并）；
- 删除会跨设备同步（墓碑机制）；
- 图片按 id 自动去重，科目卡组分享不带你的删除历史和其他模块数据。

## 五、方式②：分享卡组（发某个科目给同学）

1. 「同步」页 → 「分享卡组」区选择科目 → 点「导出该科目」；
2. 把下载的 `sxybrick-卡组-科目名-日期.json` 发给同学；
3. 同学打开应用「同步」页 →「导入数据包」选择该文件即可。

## 六、方式③：局域网一键同步（手机 ↔ 电脑）

### 5.1 电脑上启动「同步中枢」（只需一次配置，之后每次一条命令）

1. 在电脑上进入项目目录 `new_card`（资源管理器地址栏输入 `cmd` 回车打开命令行，或打开终端后 `cd` 到该目录）；
2. 运行：
   ```
   npm run hub
   ```
3. 看到 `✅ SxyBrick 局域网同步中枢已启动` 和「同步密码」即成功。**这个终端窗口保持开着**，不要关闭；
4. 同步密码会显示在启动日志里（例如 `2a69ea21ded0…`）。密码保存在 `sync-hub/hub-token.txt`，以后每次启动不变；想换密码就删掉这个文件再重新启动。

### 5.2 ★ 最关键：如何正确获取「中枢地址」

启动日志会打印一串候选地址（形如 `http://xxxx:4780`），但**里面混了很多不能用的**（VirtualBox、WSL、蓝牙、VPN 虚拟网卡等）。只需要按下面三步确认，就不会填错：

**第 1 步：先想清楚「电脑和手机现在靠什么互联」**（三选一）

| 互联方式 | 特征 | 用哪个地址 |
|---|---|---|
| A. 都连**同一个家用 WiFi** | 手机和电脑都连着同一个路由器 | 电脑 WLAN 网卡的 IPv4 |
| B. **手机给电脑供网**（手机开热点，或 USB 数据线共享） | 电脑的网是通过手机上的 | 手机共享网络里电脑分到的 IPv4（USB 共享显示为「以太网 2 / Remote NDIS」，热点显示为相应 WLAN/本地连接） |
| C. **电脑开移动热点给手机** | 手机连的是电脑的热点 | 电脑热点网卡的 IPv4（默认 `192.168.137.1`；第三方热点工具看它自己显示的地址） |

⚠️ 注意：校园网 / 商场等**公共 WiFi 通常开了"设备隔离"**，手机和电脑互相访问不了，这种网络下局域网同步会失败（提示 Failed to fetch）。此时改用 B（手机 USB 共享）或 C（电脑开热点）通常就能通。

**第 2 步：在电脑上查真实 IPv4 地址**

方法①（最通用）：按 `Win + R` → 输入 `ipconfig` → 回车，找到对应网卡段下的「IPv4 地址」。

方法②（图形界面）：设置 → 网络和 Internet →（WLAN 或 以太网）→ 点击当前网络 → 看「IPv4 地址」。

方法③（专业）：右键开始菜单 → 终端（管理员）→ 粘贴：
```powershell
Get-NetIPAddress -AddressFamily IPv4 | Where-Object {$_.IPAddress -notlike '127.*' -and $_.IPAddress -notlike '169.254.*'} | Select-Object IPAddress, InterfaceAlias
```

**第 3 步：先在本机验证，再在手机验证**

1. 电脑浏览器打开 `http://刚才查到的IP:4780` —— 能出应用页面，说明中枢在该网卡上正常服务；
2. 手机浏览器打开**同一个地址**（保持同一网络）—— 能出页面，这个地址就是最终要填的「电脑端地址」。
3. 打不开就换第 1 步里另一种互联方式重试。

> 实测案例：手机用 USB 数据线给电脑共享网络时，电脑端对应网卡是「以太网 2」，地址形如 `10.23.x.x`，手机直接访问 `http://10.23.x.x:4780` 即可同步成功；而当时 WLAN（已断开的 WiFi）地址 `10.55.96.79` 和热点虚拟网卡地址 `192.168.188.6` 都是死路（HTTP 超时）。

### 5.3 手机上执行同步

1. 手机浏览器打开 `http://电脑IP:4780`（直接打开中枢提供的应用，或使用手机已安装的应用均可）；
2. 进入「**同步**」页 → 在「电脑端地址」填入 `http://电脑IP:4780` → 点「保存」；
3. 「同步密码」填入中枢启动时显示的那串（见 5.1）；
4. 点「**与电脑一键同步**」，2 秒内提示「与电脑同步完成：卡片 +N …」即成功。

### 5.4 常见问题排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 等很久后显示 `Failed to fetch` | 地址填了"不可达网卡"的 IP（如已断开的 WiFi、虚拟机网卡） | 按 5.2 重新确定互联方式与 IP |
| 手机网页都打不开 | Windows 防火墙拦截 4780 端口 | 管理员运行：`netsh advfirewall firewall add rule name="SxyBrick Hub 4780" dir=in action=allow protocol=TCP localport=4780` |
| 同一个校园 WiFi 手机电脑互访失败 | 公共 WiFi 设备隔离（AP 隔离） | 改用「手机开热点/USB 共享给电脑」的拓扑 |
| 提示「同步失败（401）」 | 同步密码填错 | 对照中枢启动时打印的密码（`hub-token.txt`） |
| 提示「请确认电脑端中枢已启动」 | 中枢没运行 / 终端窗口被关了 / 电脑休眠 | 重新在电脑运行 `npm run hub` |
| 中枢启动报「尚未找到 dist/」 | 还没构建过前端 | 先运行 `npm run build` 再 `npm run hub` |

### 5.5 同步的原理（一句话）

手机把它的数据包发给电脑中枢（PUT /backup），中枢按「最后修改时间谁新听谁」合并并保存到 `hub-data.json`，再把合并结果返回给手机导入 —— 手机、电脑、平板三五台设备反复点「一键同步」，最终大家的数据一致，全部免费、不出内网。

## 七、日常使用建议

- **定期导出**：每周导出一份数据包存网盘，这是最后的保险；
- **先备份后清理**：清浏览器缓存/换手机前，一定先导出数据包；
- **中枢不是备份**：`hub-data.json` 只是合并中转，别把它当唯一备份；
- AI 功能需要在「AI 设置」中填入自己的 API 密钥（保存在本机浏览器）；
- 应用支持安装到桌面/主屏幕（PWA）：浏览器菜单 → 「安装应用 / 添加到主屏幕」，离线也能用。

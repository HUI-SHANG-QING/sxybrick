## 5. 可优化点（非缺陷）

### O-1 WordStudy buildTrend() 全量 toArray

- **位置**：`src/views/WordStudy.vue:56` `const rows = await db.wordReviews.toArray()`
- **问题**：加载全部 wordReviews 到内存做按日聚合。单词复习记录增长后（>5000 条）可感知延迟。
- **建议**：改为 `db.wordReviews.where('reviewedAt').aboveOrEqual(14天前).toArray()`，只取近 14 天。

### O-2 WordLearned 全量加载

- **位置**：`src/views/WordLearned.vue:68` `const list = await listWordCards({ schedulableOnly: true })`
- **问题**：加载全部可调度单词卡到内存做三态归类+筛选。单词量 >2000 时可感知延迟。
- **建议**：改为按 tab 分页查询（familiar=1 / intervalDays≥21 / 其余），或加虚拟滚动。

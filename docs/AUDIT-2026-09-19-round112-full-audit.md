## 二、关键逻辑核查（重点）

### 1. round116 图谱空白真因（你踩得最狠的）
- **根因**：AI 返回的节点经常没有 `id` 字段 → `String(n.id)` 得到字符串 `"undefined"` → 多个节点 id 全相同 → **ECharts graph 系列遇到重复节点 id 直接抛错** → 整个 `setOption` 中断 → 画布空白（已用 headless Chrome 实测复现：重复 id = 0 像素+抛错，正常 id = 2.8 万像素）。
- **修复为三层防线**（缺任何一层都会让重复 id 再穿透到 ECharts）：
  ① 入口 `generate()`：空/重复 id 补成唯一 id（n1/n2…），丢掉端点不存在或自环的边；
  ② 渲染 `buildGraphData()`：空/重复 id 节点一律丢弃（最后一道防线，任何来源的数据都过这里）；
  ③ 历史快照反解 `mindmapToGraph()`：老快照里的 `kg-undefined` 也能去重画出。
- **「假节点」修复**：图谱节点科目取自已归类的科目名，与卡片真实 subject 常不一致；原实现硬过滤导致"搜不到卡"，实际卡片在库里。现改为**科目内优先，对不上就回退全库再找**。

### 2. round118 生成后不显示（你报的"生成好几次才成功"）
- **根因**：图表容器 div 由 `v-if` 控制，首次生成时**刚插入 DOM、布局未定型（clientWidth/Height=0）**，ECharts 在 0×0 容器上 init 后画什么都是空白且不会自己恢复。
- **修复**：① initChart 后 `ensureSized()`：当帧尺寸为 0 → 下一帧强制 resize；② `ResizeObserver` 盯住容器，尺寸一变正就 resize（卸载时 disconnect 防泄漏）；③ setOption 后若尺寸仍为 0 再补一次 rAF；④ 卸载时 chart 置 null，避免复用已 dispose 实例。
- 默认界面改为 **AI 生成** + `autoLoadLatest()`：进页面自动载回**最近一条 AI 快照**（"打开就能看到上次生成的结果"，只认 AI 快照前缀、不碰用户手建导图、仅当本会话无内容时载）。真机验证：反复进出 3 次均正常绘制，无一次空白。

### 3. round114 幽灵向量（数据正确性）
- **根因**：卡片/文档正文被清空时 `indexCard/indexDoc` 直接 return，同源旧向量**既不覆盖也不写墓碑** → 幽灵行：AI 检索仍命中已删除的旧正文；且 `chunks.length || 1` 把 0 兜成 1，两道保险一起失效。
- **修复**：空正文 → 清空该卡全部向量 + 写墓碑（embeddings 为 `merge:'idOnly'`，absence≠deletion，不写墓碑对端会推回）；`embeddingRowIdsFor` 显式 0 返回空集；`indexDoc` 传真实 chunk 数。**做了负向验证**：临时改回任一旧实现，对应测试立刻变红。

### 4. round115 生成历史（kg-history.js 反解模块）
- AI 生成图谱自动存为 mindmaps 导图树（随数据包同步），新增 `mindmapToGraph()` 把它反解回「节点+关联」重新画回画布。策略"宁缺毋滥"：解析不出目标的边跳过，但节点必还原。全角括号/箭头用 unicode 转义写，规避 i18n 硬编码中文闸门（写法合规）。配套「删除历史」「覆盖式载入」二次确认。

### 5. round117 只读预览
- 图谱/导图点击节点 → `CardPreviewModal` 只读弹窗（正面/背面 Markdown 渲染 + 标签），不再 `router.push` 进卡片编辑页。纯只读、无编辑入口，职责不重叠。

### 6. round119 Markdown 6 色强调 + 边界守卫（我最细查的一块）
- 6 色体系：黄 `==高亮==` / 红 `!!标红!!` / 绿 `++解法++` / 蓝 `@@定义@@` / 橙 `^^考点^^` / 紫 `%%总结%%`。走 put() 占位符管线，内容一律 `escapeText()` 转义后拼 HTML（XSS 安全，审计实测 `<script>`/`onerror` 注入探针保持 0）。
- **边界守卫**（d625ab1）：修 `i++ 与 ++j` 里两个 `++` 被误配成一对、把中间文字染绿的问题——对编程/算法笔记是实打实的内容错乱。规则：标记外侧紧邻字符若是字母/数字/下划线则不认是标记；用 replace 回调取 offset 判断（**不用 lookbehind**，兼容旧 Safari）；中文紧贴、行首、`**==Y==**` 组合仍正常识别。6 条规则收敛到 `emph()` 辅助函数，边界逻辑只写一处。

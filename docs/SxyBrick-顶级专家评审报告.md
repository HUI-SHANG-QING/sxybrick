## 三、七维交叉审视（本轮聚焦：资产闭环与硬化缺口）

### 1. 数据资产化 / 平台生态（本轮焦点）
- **从「单机孤岛」到「闭环」**：快照（时间机器）、增量同步（省带宽）、Anki 互通（跨工具）、hub 局域网（多设备）——四个动作让「我的学习资产」第一次具备**可携带、可恢复、可迁移**属性，契合「数据主权」主张。
- **卡组市场（蓝图 P3）仍未落地**：生态闭环是「个人资产」层面，尚未到「与他人交易/订阅」的 UGC 市场层面；插件系统（R14）是其前置依赖，但前者更需要「署名/版本/审核/许可」治理。

### 2. 算法工程
- FSRS 个性化训练已可用，但 **R12 仍存**：`fsrs.js`（256 行，含梯度下降训练器）**无单测**——作为最高价值算法，数值正确性（参数收敛、权重非负、间隔单调性）必须补 `tests/fsrs.test.mjs`。
- `examAnalytics.predictPassRate`（通过率预测）是新算法面，需验证其校准（是否仅线性外推，还是基于 FSRS 状态）。

### 3. 架构 / 工程安全
- **R14（P1）仍是硬伤**：`plugins/loader.js` 仍「Blob+import() 等同 eval，无法沙箱化」，**未引入** iframe/Worker 隔离、权限声明或签名校验。插件「不进同步」降低了跨设备扩散，但本机零隔离仍是 P1。
- **0 TypeScript**：新增 3151 行核心逻辑（FSRS/插件/Exam/GenQuiz）全为裸 JS，类型安全缺失使后续重构风险高。
- 快照/增量同步复用 sync-manifest 单一事实源——同步语义一致性保持良好（架构纪律仍在）。

### 4. 学习科学 / 复习科学
- FSRS + 模考诊断 + 生成测验 + 错因闭环，已覆盖「间隔/测试/诊断/检索」四大支柱。
- 仍缺：交错练习（interle *leaving*）、检索强度分级（再认/回忆/生成）、用 `userOps` 驱动 FSRS 训练的「激活漏斗」引导。

### 5. 前端 / UI / 视觉
- 新增 Exam、GenQuiz、Plugins 三页 + 快照/Anki 入口，界面密度达「学习 OS」级。
- 待验证：虚拟滚动（千卡渲染）、移动端手势、暗/浅主题硬编码一致性。

### 6. 隐私合规（关键遗留）
- **R7′（P0 残留）**：`Export.vue` 隐私导出仍是明文 JSON/CSV（行 119-126，无 `encryptBackup`）——`privacyRecords`（情绪/压力/财务/精神心流）opt-in 后导出仍裸奔 → PIPL 最后一公里未闭。

### 7. 产品经理 / 考研用户群
- 功能广度已覆盖「复习/模考/插件/资产/同步」全链路，留存钩子齐全。
- 痛点缺口：填空式背诵（政治/作文）、真题「套卷模式」尚未作为独立流程，考研党最核心的「背诵量」场景仍未最优解。

## 七、元结论（辩证）

SxyBrick 用「单作者 + AI 编辑器 + 3 天/350 元」的持续范式，已把「本地优先复习工具」推到「带插件生态与资产闭环的学习 OS」——FSRS、插件、模考诊断、Anki 互通、增量同步这些通常需要专业团队数月的工作被高速兑现，且本轮一次性收口为可回溯基线。但本范式的内生矛盾已彻底显形：**高速广度扩张 ↔ 工程深度（隐私加密/测试/沙箱/类型）系统性欠账**。从「惊艳原型」晋级「可信赖平台」不是再堆功能，而是**把 R7′、R14、R12、TS 四块「深度债」一次性还清**。报告内含完整 v5→v6 风险登记表、量化评分卡与行动清单，可直接作为立项/验收依据。

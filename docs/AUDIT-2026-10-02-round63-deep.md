## 三、新向量①：crypto 加密备份往返（本维度内零发现）

`src/utils/crypto.js` 全链核验（AES-256-GCM + PBKDF2）：

| 检查点 | 实现 | 结论 |
|---|---|---|
| 密钥派生 | PBKDF2-SHA256 **100,000 迭代**（OWASP 推荐 ≥100k）、16 字节随机 salt | ✅ 口径达标 |
| 加密 | AES-GCM 256，**每次加密独立随机 IV**（12 字节）——无 IV 复用 | ✅ |
| 备份二进制格式 | `[version(1)][salt(16)][iv(12)][ct]`，解密前**版本字节校验**（不支持版本直接拒） | ✅ 前向兼容防线 |
| 错误口令 | GCM 认证标签天然拒绝（错误口令解密即失败），`verifyPassword` 布尔化、不泄明文 | ✅ |
| 三方案设计 | password+recovery / password-only（明示"忘=永久丢失"）/ device-key（绑设备）——风险如实告知用户 | ✅ 诚实设计 |

## 二、三个新向量的核验结果（零发现，但防线值得记录）

### 向量① 打卡 / streak 日界边界 —— 干净

- **时区口径单一**：`todayStr` 委托共享的 `dateKey`（round17 R17-11 专门消灭过"两套日期格式漂移"），本地时区补零格式，全库一个口径
- **签到幂等**：`id = c-YYYY-MM-DD`，同一天重复签到直接短路，不会刷两次
- **streak 语义正确**："今天没签就从昨天往前数"——早上还没打卡时连击不清零，符合直觉
- **fail-safe**：`ensureCheckinToday` 失败静默（签到只是副产品，不阻断复习主流程）

### 向量② 成就与统计口径 —— 干净

- **防刷三件套**：quick 行不计入（round33）、番茄只认跑满的完整会话（R18-6）、复习不足 20 次不给正确率成就
- **降级安全**：单词模块表异常时按 0 处理不阻断成就页（旧库升级过渡期安全）
- **窗口口径**：forecast 用本地零点 startOfDay，与打卡同源
- streak 判定与 word-repo 同逻辑（内联复制是"避免重依赖"的注释在案的有意取舍，格式与 dateKey 一致）

### 向量③ FSRS 权重校验 + Anki 导出转义 —— 干净

- **FSRS 权重五道防线**（`mergeUserWeights`，fsrs.js:389）：旧格式回退 → schema 版本闸 → 长度校验 → 逐项"有限非负 ≤1000"→ 任一不过全回默认。手改 meta / 脏备份导入的权重进不了调度器
- **Anki 导出转义完整**：tab/换行清洗 + `sheetCellGuard` 公式注入中和（= + - @ 开头前置单引号，WPS 打开也不中招）+ blob URL 延迟 1s 释放（R17-37）
- **Anki 导入**：300 行防呆上限 + 截断可见（R18-10）

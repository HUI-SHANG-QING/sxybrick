## 三、新向量①：回收站生命周期状态机（本维度内零发现）

回收站不只是"放进去再拿出来"，完整生命周期核验：

| 环节 | 实现 | 结论 |
|---|---|---|
| **写入**（trashItem，repo.js:318） | 快照失败**中止整个删除事务**（round68 S5：配额满时"回收站无快照 + 主行已删"= 不可恢复，故抛错回滚） | ✅ 失败路径闭环 |
| **存储** | 7 类可恢复对象（卡片/备忘/笔记/计划/文档/导图/资料）统一"快照→墓碑→删行"同事务；资料类软删保内容（恢复后标 storage='missing'） | ✅ |
| **过期** | 30 天窗口，`deletedAt` 索引查询 + bulkDelete（:344-345，非全表扫） | ✅ |
| **还原** | restoreFromTrash 按 kind 映射表路由；note 的 linkedCardIds 关联一并还原（F 系修复）；card 类型带 `_images`（round54 P1） | ✅ |

**大白话**：删东西这条路从"放进去"到"过期清走"每个弯道都有护栏——快照存不进去就不让你删（防"删了找不回"）、过期清走走索引不卡顿、还原时连图片和笔记关联都一起带回来。

## 四、新向量②：图谱环检测 + 搜索边界 + i18n 注入面（本维度内零发现）

| 子项 | 核验要点 | 结论 |

| **图谱环检测**（prereq.js） | 多层前驱 BFS 带 `visited` 集合（:48，**环防死循环**）；自引用边 `a === b` 直接跳过（:35）；新旧字段名（from/fromCardId）双兼容 | ✅ |

| **i18n 注入面** | `t()` 输出**不进任何 v-html**；i18n/index.js 无 innerHTML——翻译参数插值只走文本节点，无 HTML 注入面 | ✅ |

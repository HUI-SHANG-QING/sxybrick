## 已知限制与预留项（平台化前登记）

以下限制当前可接受，但作为平台化/开源前的预留项统一登记，避免重复讨论：

1. **单语言（无 i18n）**：全站 zh-CN 硬编码，无 i18n 抽象。本地优先个人工具可接受；
   若未来要做主题/插件市场面向多语言，需先抽取文案资源层（key → 文案映射），
   与主题 Token 分层（`base.css → semantic.css → themes/*`）一并规划。
2. **插件安全（R14，未落地）**：插件以 ES Module 字符串在应用上下文执行（Blob URL 动态 import），
   等同 eval 级权限。当前以"仅安装信任来源 + 安装后可见源码"缓解；预留：安装前明文审查 UI、
   内容哈希校验、签名校验、Worker/iframe 最低限度沙箱。
3. **导出加密（R7′，未落地）**：`utils/crypto.js`（AES-GCM + PBKDF2）已就绪，但 `Export.vue`
   尚未接线加密导出；含 `privacyRecords` 的备份目前为明文。
4. **文档注释与代码版本脱节**：README 中 Dexie 版本/表数/测试数需随 db 版本升级同步刷新。

## 三、本轮修复的四个实际问题

### 1. 卡片联动分析输出裸 JSON（用户主诉）

- **现象**：预设分析输出 `{"type":"timeline", "data":[...]}` 这样的原始文本，不渲染成时间线。
- **根因**：上游 `src/analysis/ai-analyzer.js` 的 `extractJSON` 解析失败时，把原始字符串当普通文本直接吐给视图；而 `CardLinkAnalysis.vue` 的 timeline 渲染分支本身是好的。
- **探针结论**：实测只有**被截断的 JSON** 才会解析失败，完整 JSON 正常。
- **修复**：
  - `src/utils/llm-json.js` 新增 `repairTruncated()`：扫描字符串进出状态，补全未闭合引号 / 括号，抢救被截断的结构化输出。
  - `ai-analyzer.js`：解析失败时若原文形似结构化信封（`` ``` `` / `{` / `[` 开头且含 `"type"` / `"data"`），**抛错**让 `link-engine` 降级到本地分析，而不是把裸 JSON 当文本展示。
- **回归测试**：`tests/round103-render-and-features.test.mjs`（截断 JSON 可修复；字符串内花括号不受影响；timeline 可渲染）。

### 2. 费曼学习法读不到卡片正文

- **现象**：喂给模型的卡片内容被砍成残句，卡片里的图片引用也丢了。
- **根因**：`enrichedToText` 用 `.slice(0,100)` / `.slice(0,140)` 硬切。
- **修复**：改用 `clipText(...,400)` / `clipText(...,600)`。`clipText` 是**图片感知**的，会保留 `sxy-img://<uuid>` 引用不被腰斩，因此 `enrichForLlm` 仍能把图片作为附件送出。同时补了范围说明（共 N 张，此处列前 M 张）。

### 3. 英语单词本只能逐条删除

- **修复**：新增批量管理模式——`batchMode` / `selIds` 状态、卡片复选框、全选 / 清空 / 删除选中动作条，删除走循环 `deleteWordCard`。i18n 在 `src/i18n/views/wordBook.js` 补了 zh + en 共 9 个键（batchManage / batchExit / batchSelectAll / batchClear / batchSelected / batchDelete / confirmBatchDelete / batchDeleted / batchNone）。

普通问答（AI 学习助手）调用写工具前须弹框经用户批准；Agent 模块行为不变。

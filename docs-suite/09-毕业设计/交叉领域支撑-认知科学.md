# 交叉领域支撑：认知科学与教育测量

> 本系统的算法并非纯工程技巧，背后有认知科学与教育测量学依据。论文/答辩可从这些角度展开。

## 1. 记忆的保持率模型（认知心理学）

间隔重复的心理学基础是"遗忘曲线"：记忆痕迹随时间指数/幂律衰减。FSRS 的保持率函数
R(t)=(1+t/9S)^-1 本质上是一个幂律衰减模型，S 刻画衰减速度（稳定度）。
- **对答辩的话**：我们不是拍脑袋定间隔，而是用一个有参数化的衰减曲线来预测"你现在还记得多少"。

## 2. 间隔效应（Spacing Effect）

认知心理学实证：分散学习比集中学习记忆更牢。系统在"即将遗忘"的时刻安排复习，正是间隔效应的工程化。

## 3. 检索练习（Retrieval Practice / Testing Effect）

"回忆本身强化记忆"。复习时先自己想答案再翻面，比反复阅读更有效。系统的"先回忆后评分"流程就是检索练习。

## 4. 校准（Calibration，教育测量学）

学生常"以为自己会了"。校准回测对比"模型预测你记得 80%"与"实际答对率"，Brier 分数与 ECE 是教育测量里评估预测准确度的标准指标。这让"调度是否科学"可量化，而非自说自话。

## 5. 个性化与自适应学习

系统用用户自己的数据训练权重，属于自适应学习系统（Adaptive Learning）范畴：每个学习者得到不同的间隔策略。

## 6. RAG 与教育问答的关系

教育场景里 AI 最大的风险是"编造"。RAG 把回答锚定到用户自有材料，是对幻觉的工程约束，可在论文里讨论"AI 在教育中的可信度"。

## 7. 可写进论文的交叉点

- 认知心理学：间隔效应、检索练习、遗忘曲线。
- 教育测量：Brier、ECE、校准。
- 人机交互：本地优先与隐私计算、PWA。
- 软件工程：纯函数算法+高测试覆盖的可维护性实践。

# 毕业设计任务书

## 课题名称
基于间隔重复算法与多智能体协作的本地优先智能记忆卡片系统

## 学生信息
姓名／学号／专业：＿＿＿＿（按实际填写）　指导教师：＿＿＿＿

## 一、设计目的
设计并实现一款面向考研与自学场景的智能记忆卡片系统，以科学记忆调度算法为核心，结合 AI 辅助与本地优先架构，提升复习效率并保护用户数据隐私。

## 二、设计内容

1. **需求分析**：梳理卡片管理、复习调度、AI 辅助、学习分析、跨设备同步等功能需求。
2. **系统设计**：三层架构（表现层/智能层/数据层）、数据模型、同步协议设计。
3. **核心算法实现**：FSRS-4.5 调度、权重训练、校准回测、到期预测。
4. **AI 子系统**：ReAct 智能体编排、工具注册、RAG 检索、多智能体黑板。
5. **实现与测试**：Vue 3 + IndexedDB 实现，1000+ 自动化测试。
6. **部署与文档**：GitHub Pages 部署，撰写毕业论文。

## 三、技术要求

- 前端：Vue 3 / Vite / Pinia / Dexie(IndexedDB)。
- 算法：FSRS-4.5、向量混合检索、知识图谱。
- 质量：单元测试、静态检查、构建验证。

## 四、预期成果

- 可运行的系统（在线演示地址）。
- 源代码与完整文档。
- 毕业论文一篇。

# 需求分析

## 1. 功能性需求

### 用户角色
系统无注册用户，数据属于当前设备使用者；AI 能力由用户自备 Key 开启。

### 用例清单

| 编号 | 用例 | 描述 |
|---|---|---|
| UC1 | 管理卡片 | 新建/编辑/删除/分组/标记卡片 |
| UC2 | 间隔复习 | 按 FSRS 到期队列复习，评分后自动调度 |
| UC3 | AI 拆卡 | 粘贴材料自动生成卡片候选 |
| UC4 | AI 出题 | 按薄弱点组卷 |
| UC5 | 智能问答 | 基于 RAG 回答学习问题 |
| UC6 | 学习分析 | 查看掌握度、薄弱科目、校准、预测 |
| UC7 | 单词复习 | 生熟词、词组、长难句间隔复习 |
| UC8 | 资料导入 | PDF/Word/OCR 提取 |
| UC9 | 知识图谱 | 查看与自动构建知识关系 |
| UC10 | 跨设备同步 | 局域网/JSON 同步与合并 |

## 2. 非功能性需求

- **离线可用**：已加载内容断网可复习（PWA）。
- **隐私**：学习数据本地存储，AI 请求走用户自有端点。
- **性能**：千卡规模检索秒级。
- **可维护**：算法纯函数化，1000+ 测试。
- **兼容**：桌面/移动浏览器自适应。

## 3. 数据需求

核心实体：卡片、复习记录、计划、文档、图谱边、单词、模考、向量。每实体需唯一标识、时间戳、同步元数据。

## 4. 约束

- 无应用服务器；AI 依赖外部大模型端点。
- 不做官方题库。

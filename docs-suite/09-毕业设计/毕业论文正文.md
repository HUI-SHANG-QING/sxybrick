# 基于间隔重复算法与多智能体协作的本地优先智能记忆卡片系统

> 本科毕业设计论文正文（结构稿，按学校模板调整格式即可）

---

## 摘要

针对考研与自学场景中"复习安排不个性化、制作卡片成本高、学习数据隐私难保障"三大问题，本文设计并实现了一个本地优先（local-first）的智能记忆卡片系统 SxyBrick。系统以新一代间隔重复算法 FSRS-4.5 为调度核心，根据用户历史复习记录预测记忆保持率并动态安排复习间隔；在此之上构建基于检索增强生成（RAG）的多智能体子系统，由 10 个领域智能体通过统一工具协议协作，完成自动拆卡、出题、错题归因与知识图谱构建。系统采用纯前端架构，全部学习数据存储于浏览器 IndexedDB，支持离线使用与跨设备字段级合并同步。实验表明，系统核心逻辑由 1079 项自动化测试覆盖，调度算法经校准回测可量化评估预测准确性。

**关键词**：间隔重复；FSRS；检索增强生成；多智能体；本地优先；记忆卡片

---

## Abstract

Aiming at three problems in postgraduate-exam and self-study scenarios—non-personalized review scheduling, high cost of making flashcards, and weak privacy of learning data—this paper designs and implements SxyBrick, a local-first intelligent flashcard system. The system adopts the FSRS-4.5 spaced-repetition algorithm to predict memory retention and dynamically schedule review intervals. On top of it, an RAG-based multi-agent subsystem with ten domain agents collaborates through a unified tool protocol to auto-generate cards, compose quizzes, attribute mistakes, and build a knowledge graph. Built as a pure front-end PWA, all learning data is stored in the browser's IndexedDB, supporting offline use and cross-device field-level merge sync. The core logic is covered by 1079 automated tests, and the scheduler is evaluated by calibration backtesting.

**Keywords**: spaced repetition; FSRS; RAG; multi-agent; local-first; flashcard

## 第 1 章 绪论

### 1.1 研究背景
记忆是学习的基础，但"记了忘、忘了记"长期依赖经验式安排。固定艾宾浩斯时间表对所有用户一刀切，忽略了个体记忆差异与不同知识卡片的难度差异。同时，大语言模型的兴起为"自动做卡、智能答疑"提供了新可能，但主流学习应用多为云端账号模式，学习数据由平台持有。

### 1.2 研究意义
- 用可量化的记忆模型替代经验式排期；
- 用 AI 降低做卡成本；
- 用本地优先架构保护学习数据隐私。

### 1.3 主要工作
1. 实现 FSRS-4.5 调度与个性化权重训练、校准回测；
2. 设计基于 RAG 的多智能体协作学习助手；
3. 实现本地优先存储与无云后端的跨设备同步；
4. 工程化交付：1079 项测试、PWA 离线、GitHub Pages 部署。

## 第 2 章 相关技术

### 2.1 间隔重复与 FSRS
间隔重复利用"即将遗忘时复习记忆效果最好"的心理学规律。FSRS（Free Spaced Repetition Scheduler）用稳定度 S 与难度 D 两个状态量，通过保持率函数 R(t)=(1+t/9S)^-1 刻画记忆随时间的衰减，并按目标保持率反解下次复习间隔。相比传统 SM2 的固定公式，FSRS 的参数可由用户数据训练。

### 2.2 检索增强生成（RAG）
RAG 先从知识库检索与问题相关的片段，再交由大模型基于这些片段生成回答，可显著降低幻觉。本系统将用户自有卡片与文档向量化，作为检索源。

### 2.3 多智能体与 ReAct
ReAct（Reason+Act）让模型在"思考—调用工具—观察结果"间循环。多个专长不同的智能体通过黑板共享中间产物，可完成更复杂的学习任务。

### 2.4 本地优先与 IndexedDB
本地优先软件把数据放在用户设备，通过字段级合并与墓碑实现多端同步，不依赖中央服务器。浏览器 IndexedDB 提供事务与索引能力。

## 第 5 章 关键实现

### 5.1 FSRS 调度
实现保持率函数与评分→状态更新，加入稳定度封顶、难度有界、概率钳制等护栏；用有限差分梯度下降基于用户复习记录训练 19 个权重。

### 5.2 校准回测
把历史记录按"模型预测保持率"分桶，对比实际答对比例，计算 Brier 分数与 ECE，量化调度准确性。

### 5.3 RAG 检索
问题向量化后与本地向量库算余弦相似度，再与关键词分按 0.65/0.35 加权融合取 top-k。远程嵌入失败时降级本地模型并落降级签名，恢复后自动重建。

### 5.4 多智能体
ReAct 编排器循环调用注册表中的工具；10 个智能体各有 system prompt，可互相委托；协作模式经黑板共享发现与产出。

### 5.5 跨设备同步
每个可编辑字段记时间戳；同字段冲突取较新者，平局用确定性 tiebreaker；删除写墓碑并随同步传播。

### 5.6 可靠性兜底
工具拿到数据但总结步骤失败时，用确定性模板本地渲染结果，不丢用户数据。

## 第 6 章 测试与评估

### 6.1 测试方法
采用 Node 内置测试框架，fake-indexeddb 模拟数据库，115 个测试文件、1079 个用例，覆盖算法、数据层、AI 工具、同步合并。

### 6.2 结果
- 自动化测试 1079/1079 通过；
- ESLint 0 告警；
- 生产构建通过；
- 多轮深度审计未发现 P0/P1 缺陷。

### 6.3 讨论
系统在千卡规模下检索秒级；纯前端架构使部署零成本；代价是无云账号与多租户能力。

## 第 7 章 总结与展望

本文实现了一个本地优先的智能记忆卡片系统，将 FSRS、RAG 与多智能体技术集成到同一隐私优先的架构中。未来可引入端上小模型、更精细的知识图谱推理与多人协作。

# 系统设计

## 1. 总体架构

采用三层结构：

```
表现层  Vue3 SPA（路由/视图/状态/可视化）
   ↓ 调用命名函数，不直接操作存储
智能层  ReAct 编排 / 工具注册表 / RAG / 黑板 / 记忆
   ↓ 通过 repo 层读写
数据层  Dexie/IndexedDB / FSRS 算法 / 图谱 / 同步合并
```

关键设计：UI 不碰 SQL、算法与 UI 隔离、AI 与数据隔离。

## 2. 模块划分

- **卡片与复习模块**：CRUD、复习队列、评分调度。
- **算法模块**：FSRS、校准、预测、错题归因、图谱。
- **AI 模块**：编排器、工具、智能体、检索、记忆。
- **单词模块**：生熟词、词组、长难句。
- **资料模块**：PDF/Word/OCR 解析。
- **同步模块**：传输、合并、墓碑。

## 3. 数据模型设计

见《数据模型与存储设计》。核心：每表建索引；卡片状态机由算法驱动；删除走事务+墓碑。

## 4. 关键流程设计

### 4.1 复习流程
评分 → schedule 更新 S/D/dueAt → 写复习记录 → 通知 UI。

### 4.2 AI 问答流程
问题 →（需要时）RAG 检索相关卡片 → 拼上下文 → LLM 生成 → 渲染；LLM 失败时本地兜底。

### 4.3 同步流程
变更 → 生成增量 → 对端按字段时间戳合并 → 墓碑传播。

## 5. 接口设计（内部）

- repo 层对外暴露命名函数（getStats/listCards/createCard/reviewCard 等）。
- AI 工具统一 `execute(args, ctx)` 返回 `{ok, data, error}`。

## 6. 异常与边界设计

- 空库返回空结构；脏数据兜底；向量降级落签名；合并确定性。

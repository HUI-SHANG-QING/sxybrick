# 开题报告

## 1. 选题依据

自学与考研场景中，记忆复习普遍存在三个问题：
- **不个性化**：固定艾宾浩斯表对所有人一刀切，忽略个体与卡片差异。
- **做卡成本高**：手动把讲义做成几百张卡片费时费力。
- **数据隐私**：主流应用为云端账号模式，学习数据由平台持有。

FSRS 等新一代间隔重复算法已在开源社区证明其优于传统 SM2；LLM 与 RAG 让"自动做卡、智能答疑"可行。本课题将二者结合，并采用本地优先架构解决隐私问题。

## 2. 国内外研究现状

- **间隔重复**：从 SM2（SuperMemo）发展到 FSRS，后者用可调度的记忆保持率模型替代固定间隔，可基于用户数据训练。
- **智能学习系统**：近年产品逐步引入 AI，但多为封闭云端、无本地数据控制。
- **Local-first 软件**：随着 IndexedDB/CRDT 等技术成熟，"数据在本地、端上合并"成为新趋势。
- **RAG**：检索增强生成让 AI 回答基于用户自有资料，减少幻觉。

## 3. 研究方案

- **架构**：纯前端 PWA + Dexie/IndexedDB，可选局域网同步中枢。
- **算法**：实现 FSRS-4.5，做权重训练与校准回测。
- **智能体**：ReAct 循环 + 工具注册表 + 10 个领域智能体 + 黑板协作。
- **检索**：远程 embedding 优先、本地降级，语义+关键词混合打分。
- **同步**：双时间戳字段级合并 + 墓碑传播。

## 4. 可行性分析

- 技术成熟、无服务器成本、浏览器即可运行。
- 本人已完成原型并多轮迭代、补测试，进度可控。

## 6. 预期难点与对策

| 难点 | 对策 |
|---|---|
| FSRS 数值稳定性 | 稳定度封顶、概率钳制、防除零、大量单测 |
| 向量模型降级后一致性 | 落模型签名，恢复自动重建 |
| 多端合并冲突 | 确定性 tiebreaker + 墓碑 |
| AI 幻觉 | RAG 基于真实卡片回答，无资料时如实告知 |

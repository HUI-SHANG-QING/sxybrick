# 构建、部署与运行

## 环境要求

- Node.js 18+（推荐 20 LTS）
- npm 9+

## 本地开发

```bash
npm install        # 安装依赖
npm run dev        # Vite 开发服务器（热更新）
```

## 生产构建

```bash
npm run build      # 产出 dist/（Vite 6 + PWA）
npm run preview    # 本地预览生产构建
```

## 测试与质量门禁

```bash
npm test           # 完整质量门（注意：不是只跑单测）
```

`npm test` 实际按顺序跑：
1. `check-view-i18n.mjs --strict` — 界面文案 i18n 闸门（禁硬编码中文）
2. `check-view-i18n.mjs --js` — 数据层硬编码中文检查
3. `dep-check.mjs` — 依赖安全/版本检查
4. `node --test tests/*.test.mjs` — 1079 项单元/集成测试（串行）

其他脚本：

```bash
npm run lint           # ESLint
npm run lint:fix       # 自动修
npm run format         # Prettier
npm run benchmark      # 算法基准
npm run hub            # 启动局域网同步中枢
```

## 部署

这是纯静态 PWA，部署到任意静态托管即可：

- **GitHub Pages**（当前在用）：构建后推送 `dist/` 到 GitHub Pages 分支，访问 hui-shang-qing.github.io/sxybrick。
- **任意静态服务器 / Nginx**：把 `dist/` 放上去即可。
- **PWA**：vite-plugin-pwa 生成 service worker，首次加载后可离线打开。

## 局域网同步中枢

```bash
npm run hub        # 启动 sync-hub，监听本地端口
```
另一台设备在"同步"页填入本机 IP 即可互传。首次运行参考 `sync-hub/allow-firewall.bat` 放行防火墙。

## 目录约定

- `dist/` `dev-dist/`：构建产物，不进版本库。
- `dist_bak_*`：历史构建备份。
- `outputs/` `experiments/`：实验与输出。

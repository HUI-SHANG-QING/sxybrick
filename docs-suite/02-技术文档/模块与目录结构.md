# 模块与目录结构

> 对应真实仓库 `src/` 布局。

## 顶层

```
src/
├── main.js            应用入口（挂载 Vue、注册全局、未捕获异常兜底）
├── App.vue            根组件
├── router.js          路由表（48 视图）
├── db.js              Dexie 数据库 schema（v16，16+ 表）与连接
├── repo.js / repo-core.js   卡片/复习/计划/文档等业务 CRUD
├── word-repo.js       英语单词本数据层（熟词/生词/词组/长难句）
├── docs-lib.js        资料库文件（PDF/docx/图片）的解析与查询
├── fsrs.js            FSRS-4.5 记忆调度核心
├── srs.js / achievements.js / classify-lib.js  调度封装/成就/分类
├── sync.js / sync-manifest.js / sync-status.js / sync-dedup.js
│                      跨设备同步：传输、字段级合并、状态、去重
├── images.js / ai.js / intelligence.js
├── styles.css / styles/
├── i18n/              中英文案字典
├── views/             48 个页面组件
├── components/        可复用组件
├── composables/       Vue 组合式函数
├── stores/            Pinia 状态
├── services/          图片分析/OCR/多模态等服务
├── algorithms/        纯算法（见下）
├── agent/             AI 智能体子系统（见下）
├── analysis/ search/ plugins/ workspace/ data/
```

## algorithms/（纯函数算法，零 DOM）

| 文件 | 职责 |
|---|---|
| fsrs.js | 调度核心（在 src/ 根，算法目录是封装） |
| scheduling.js | 评分→下次到期 |
| session.js | 一次复习会话编排（含错题交错排序） |
| calibration.js | 校准回测：预测记忆概率 vs 实际正确率（Brier/ECE） |
| forecast.js | 未来 N 天到期洪峰预测（含"复习后再到期"推进模拟） |
| pretest.js | 前测（如线性代数熟悉度）冷启动 |
| graphAuto.js | 从标签共现/错题同现/内容相似自动推导图谱边 |
| graph-resolve.js / prereq.js | 图谱解析、前置依赖回溯 |
| mistakeAttribution.js | TF-IDF 把错题按概念聚类 |
| mindmap-graph.js | 思维导图布局 |
| adaptive-retention.js / golden-hours.js / calibration-feedback.js | 自适应保持率/黄金复习时段/校准反馈 |
| networth.js / source-trace.js | 学习资产净值/来源溯源 |
| fsrs-benchmark.js | 算法基准测试 |

## agent/（AI 智能体子系统）

| 文件 | 职责 |
|---|---|
| orchestrator.js / pipeline.js / pipeline-core.js | ReAct 编排、多智能体流水线 |
| registry.js | 工具注册表 + 智能体注册表（开闭扩展） |
| tools/ | 40+ 工具实现（查询/建卡/出题/检索/黑板读写） |
| agents/ | 10 个智能体定义 |
| retrieval.js / retrieval-core.js / embedding.js | 向量混合检索、嵌入生成与降级 |
| blackboard.js | 多智能体协作黑板 |
| memory.js | 长期记忆（分层：核心/偏好/事实） |
| proactive.js | 主动建议/轻量检查调度 |
| local-answer.js | 有数据时的本地兜底渲染 |
| llm.js / reply.js / context.js / attribution.js | LLM 调用、回复、上下文拼装、来源归因 |
| analytics.js / examAnalytics.js | 学习分析、模考分析（趋势/通过率预估） |
| stale.js | 久未复习卡检测 |

## views/（页面，48 个，按功能域）

- **卡片与复习**：Cards, Review, CardGroups, CardInsight, WrongBook, GenQuiz, Exam
- **单词英语**：WordBook, WordReview, WordStudy, WordLearned, WordPhrases, WordGroups, WordHub, WordAIModes, WordExport, WordSettings
- **规划与报告**：DailyPlanView, Plans, WeeklyReport, Stats, UserDashboard, Dashboard
- **知识图谱与思维**：KnowledgeGraph, Mindmap, CardLinkAnalysis, Feynman, Pomodoro
- **资料与文档**：Library, LibraryFiles, Docs, NotesView
- **AI**：AIAssistant, AgentWorkbench
- **系统**：Sync, Export, PrivacyData, RecycleBin, Search, Memo, Health, Plugins, Achievements, CategoryView, UIKit, Workspace

## 支撑目录

- `tests/`：115 个测试文件，1079 个用例（node --test）。
- `scripts/`：工程脚本——i18n 闸门、依赖检查、force-add/commit（绕 Windows Defender 拦截）、基准测试。
- `sync-hub/`：局域网同步中枢（Node）。
- `public/` `dist/`：静态资源与构建产物。

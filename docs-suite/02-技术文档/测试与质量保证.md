## 质量门禁（npm test 不是只跑测试）

提交前 `npm test` 会按顺序强制：
1. i18n 严格检查（界面文案）
2. 数据层中文检查
3. 依赖检查
4. 全部单测

任何一项失败，本次提交就不应合入。

## 工程纪律（真实执行中）

- **算法纯函数化**：fsrs/retrieval/图谱零 DOM 零网络，Node 直测——这是高测试覆盖率能做到的前提。
- **边界全覆盖**：空库、单条、越界、脏数据、并发同毫秒，都有对应用例。
- **数值护栏**：稳定度封顶、难度有界、概率钳 [0,1]、防除零。
- **多轮自审**：仓库 `docs/AUDIT-*.md` 有 30+ 轮深度代码审计记录，每轮记录发现的问题与修复（死边误删、向量降级签名、并发重复推送等真实缺陷都被发现并回归测试兜底）。
- **CRLF/Windows 兼容**：工作区文件为 CRLF，脚本替换前先归一化，避免"改了但匹配不上"。

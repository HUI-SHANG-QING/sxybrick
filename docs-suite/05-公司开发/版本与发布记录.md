# 版本与发布记录

## 发布节奏说明

本项目采用小步快跑：功能/修复随时提交 main，GitHub Pages 自动部署。
版本号见 `package.json`，当前 **v2.0.0**。

## 版本号约定

- 主版本：架构级变更（如数据库 schema 大改、存储迁移）。
- 次版本：新增功能。
- 修订：修复与优化。

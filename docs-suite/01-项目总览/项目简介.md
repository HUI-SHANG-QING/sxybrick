# 项目简介 — SxyBrick 记忆卡片

## 一句话

SxyBrick 是一套**本地优先（local-first）的考研记忆卡片系统**：用现代间隔重复算法（FSRS）科学安排复习，内置 10 个 AI 智能体帮你拆卡、出题、找薄弱点，数据全部存在你自己浏览器里，断网可用，零服务器成本。

在线体验：https://hui-shang-qing.github.io/sxybrick/

## 它解决什么问题

考研复习最大的痛点不是"记不住"，而是**不知道什么时候该复习什么**。传统艾宾浩斯曲线是固定的"第 1、2、7、15 天"，对所有人一刀切。SxyBrick 解决三件事：

1. **该复习什么，让算法算**：每张卡根据你的历史表现（记住/遗忘、稳定度、难度）预测"你现在还记得多少"，只在快忘的时候提醒你。
2. **薄弱点在哪里，让数据指出来**：自动统计哪类题反复错、哪个科目很久没碰、哪张卡快到期，不用自己凭感觉。
3. **AI 帮你减负**：把一段讲义丢进去，自动拆成卡片、自动出题、自动找知识间的前置关系；不用手动一张张做卡。

## 核心特色（真实功能，不是 PPT 概念）

| 特色 | 实际实现 |
|---|---|
| FSRS 间隔重复 | 基于记忆可提取性方程 R=(1+t/9S)^-1，19 个可调权重，支持用你的复习记录**训练权重**、校准回测、到期洪峰预测 |
| 本地优先 PWA | 卡片/复习记录/AI 对话/知识图谱全存 IndexedDB；AI 只调用你自己填的 API Key，学习数据不出本机；可离线使用 |
| 10 个 AI 智能体 | 导师/分析师/制卡师/出题官/规划师/记忆管家/助记师/错题分析师/图谱构建/智能复习官，通过统一工具协议协作 |
| RAG 检索 | 用户提问时，先从你的卡片库/文档里向量检索相关内容，再交给 AI 回答，不瞎编 |
| 知识图谱 | 自动推导卡片间的"前置依赖/对比/相关"关系，复习时先补前置再练当前 |
| 跨设备同步 | 局域网同步中枢（hub）或 JSON 备份；双时间戳字段级合并 + 墓碑机制，编辑进度互不覆盖 |
| 单词/英语学习 | 完整单词本（熟词/生词/词组/长难句）、间隔复习、释义/搭配/例句补全 |
| 学习分析 | 费曼讲解、番茄钟、模考分析与通过率预估、每周报告、学习画像六维雷达 |
| 资料导入 | 支持 PDF、Word(docx)、图片 OCR、Excel，自动提取文字做卡片 |

## 谁在用

- 考研学生（计算机组成原理、线性代数、操作系统、数据结构、编译原理等）
- 想要"数据都在自己手里"、不信任云端题库的自学者

## 与同类产品的差异

- **比 Anki**：有 AI 智能体帮你拆卡出题、有图形化知识图谱、有中文本地化与中文 UI、面向考研场景预置能力。
- **比 不背单词/墨墨**：不只是英语单词，而是全科知识卡片；数据完全本地可控，不依赖付费云端。
- **比 Notion/普通笔记**：有真正的记忆调度算法，不是"记了就完"，而是按遗忘曲线逼你复习。

# 常见问题（FAQ）与故障排查

## 数据相关

**Q：换浏览器/清缓存后数据没了？**
A：本应用数据存在浏览器本地。换浏览器或清缓存前，务必用"导出"功能做 JSON 备份，到新环境导入。

**Q：手机和电脑数据不一样步？**
A：用同步页的局域网中枢或手动 JSON 导入导出。合并是字段级的，两边各自改的内容会保留；同字段冲突以较新的为准。

**Q：删了一张卡，另一台设备上又冒出来？**
A：确认同步已完成。删除走墓碑传播，正常情况下对端会收到删除标记。若没生效，导出后重同步一次。

## AI 相关

**Q：AI 回答"查不到"或报错？**
A：①确认设置里 API Key 填对；②确认网络；③如果是检索问题，先点"更新索引"（ensureIndex）把新卡纳入向量索引。

**Q：AI 答非所问？**
A：它是基于你库里已有内容回答的。如果库里没相关卡片，它会如实说没有，而不是瞎编。可以先建相关卡片。

**Q：填了 Key 还是不能用 AI？**
A：Key 存在 localStorage，与浏览器同源绑定。换设备需重新填。

## 复习与算法

**Q：为什么有的卡天天让我复习，有的很久才来？**
A：这是 FSRS 算法按你每次的评分算的。答对且熟练的间隔会自动拉长，答错的会缩短。不是固定艾宾浩斯表。

**Q：到期预测里某天突然有很多卡？**
A：那是"到期洪峰"。可以提前几天分散复习，或让系统把当天重学的卡跳到次日。

## 资料导入

**Q：上传的扫描 PDF 识别不出文字？**
A：扫描件没有文字层，系统会把页面图交给多模态模型"看图"。若你的模型不支持图片，请到"设置→图片分析策略"调整。

**Q：图片/大文件导入慢？**
A：大文件 OCR 需要时间，属正常；资料库文件原文件较大，定期清理不用的资料。

## 工程/部署

**Q：本地跑不起来？**
A：确认 Node 18+，重新 `npm install`，再 `npm run dev`。

**Q：`npm test` 失败？**
A：测试不只跑用例，还跑 i18n 和依赖门禁。看输出最上面的失败项：若是 i18n 行号位移导致，按项目说明重认领基线；若是用例失败，按报错修。

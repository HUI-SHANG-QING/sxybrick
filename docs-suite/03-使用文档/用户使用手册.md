# 用户使用手册

## 一、这是什么

SxyBrick 是一个帮你科学复习的记忆卡片应用。你把知识点做成卡片（问题在正面、答案在背面），它会用算法告诉你"今天该复习哪些、该学哪些新的"。所有数据存在你自己的浏览器里，断网也能用。

## 二、第一次用

1. 打开网页（或部署后的地址）。
2. 不需要注册账号——数据直接存在本机浏览器。
3. 想让 AI 帮忙拆卡/讲解：到"设置"里填你自己的大模型 API Key。不填也能用基础复习功能。

## 三、日常流程（最小可用）

### 第 1 步：建卡
- 手动：卡片页 → 新建卡片 → 填正面（问题）、背面（答案）、科目。
- 用 AI：把一段讲义/笔记粘给 AI，让它"拆成卡片"。
- 导资料：资料库页上传 PDF/Word/图片（图片会 OCR 出文字）。

### 第 2 步：复习
- 进"专注背诵/复习"页，系统按算法排好今天到期的卡。
- 看到正面，回忆答案，按空格翻面。
- 给自己评分：想得起=记得牢，想不起=忘了（系统据此调整下次复习时间）。

### 第 3 步：看数据
- 复习数据页：正确率、掌握度分布、校准曲线、未来到期量。
- 仪表盘：今天背了多少、哪科弱、连续学习天数。

## 四、主要功能区

| 功能区 | 干什么 |
|---|---|
| 卡片 / 复习 | 建卡、按到期队列复习 |
| 单词本 | 英语单词：生词/熟词/词组/长难句，间隔复习 |
| 每日规划 | 排今天的学习任务，看完成进度 |
| 知识图谱 | 看知识点之间的前置/关联关系 |
| 费曼 | 用自己的话讲一遍，AI 帮你挑错 |
| 番茄钟 | 专注计时 |
| 模考 | 组卷、记录成绩、看通过率预估 |
| 资料库 | 上传 PDF/Word/图片，提取文字做卡 |
| 导出 | 导出卡片/数据备份（JSON/Excel） |
| 同步 | 手机/电脑之间同步进度 |

## 五、跨设备同步

- 方式一：两台设备在同一局域网，启动同步中枢（`npm run hub`），在同步页填对方地址。
- 方式二：导出 JSON 备份，拷到另一台设备导入。
- 你的编辑和另一台的编辑会自动合并，不会互相覆盖；这边删了那边也会删。

## 六、数据安全

- 所有学习数据只在你本机浏览器（IndexedDB）。
- AI 请求用你自己的 Key，不经过官方服务器。
- 定期用"导出"做 JSON 备份，换浏览器/清缓存前先导出。

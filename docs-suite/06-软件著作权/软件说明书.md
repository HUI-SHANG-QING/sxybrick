# 软件说明书（软著登记版）

## 软件名称
SxyBrick 智能记忆卡片系统 V2.0

## 软件用途
本软件面向考研学生与自学者，提供基于科学间隔重复算法的记忆卡片复习功能，并集成 AI 辅助学习、知识图谱、学习数据分析与跨设备同步。

## 运行环境
- 浏览器：Chrome / Edge / Firefox / Safari（现代版本）。
- 本地开发：Node.js 18+。
- 可选：用户自备大模型 API Key 以启用 AI 功能。

## 主要功能

### 1. 卡片管理
支持新建、编辑、删除知识卡片，按科目/标签分类，支持标记、错因记录、口诀与软删除回收站。

### 2. 智能复习调度
采用 FSRS-4.5 间隔重复算法，根据用户每次复习的评分动态计算下次复习时间，支持权重个性化训练、校准回测与未来到期洪峰预测。

### 3. AI 辅助学习
内置 10 个领域智能体，可将学习材料自动拆解为卡片、按薄弱点出题、结合用户已有卡片进行概念讲解。基于向量检索的 RAG 机制确保回答基于用户真实学习内容。

### 4. 学习分析
提供掌握度、正确率、薄弱科目、学习画像雷达、模考成绩趋势与通过率预估等分析功能。

### 5. 知识图谱
自动推导知识点间的前置依赖与关联关系，复习时先补前置、再练当前。

### 6. 英语单词学习
提供生词/熟词/词组/长难句分类与间隔复习。

### 7. 资料导入
支持 PDF、Word 文档与图片 OCR 提取文字并生成卡片。

### 8. 跨设备同步
通过局域网同步中枢或 JSON 备份实现多端数据同步，字段级合并，删除墓碑传播。

## 技术特点
- 纯前端本地优先架构，数据存储于浏览器 IndexedDB，支持离线使用。
- 采用 Vue 3 + Vite + Dexie 技术栈。
- 1079 项自动化测试保障质量。

## 操作说明
新建卡片 → 在复习页按到期队列复习并自评 → 在数据页查看分析。详细操作见《用户使用手册》。

# 交付物清单

> 本清单列出向甲方/校方交付时应包含的全部材料。

## 一、软件本体

| 交付物 | 位置/形式 | 说明 |
|---|---|---|
| 源代码仓库 | 完整 Git 仓库（含提交历史） | main 分支 |
| 生产构建产物 | `dist/` | `npm run build` 产出，可直接部署 |
| 在线演示地址 | GitHub Pages 链接 | 免安装体验 |
| 局域网同步中枢 | `sync-hub/` | 随源码交付 |

| 类别 | 文档 |

## 四、运行环境

- 浏览器：现代 Chrome/Edge/Firefox/Safari。
- 本地开发：Node 18+。
- AI 功能：用户自备大模型 API Key。

## 五、不交付项（说明）

- 官方云服务器与账号体系：本系统为本地优先设计，不含云后端。
- 第三方大模型 API Key：由部署方自行申请。
- 内置题库：系统不自带题目，由用户自建或 AI 生成。

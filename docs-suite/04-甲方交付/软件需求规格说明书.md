# 软件需求规格说明书（甲方交付版）

## 1. 引言

### 1.1 编写目的
本文档说明"SxyBrick 智能记忆卡片系统"的功能与非功能需求，作为开发、交付与验收依据。

### 1.2 产品定位
面向考研/自学人群的本地优先记忆卡片系统，以 FSRS 间隔重复算法为核心，叠加 AI 辅助拆卡、出题、学习分析与跨设备同步。

## 2. 功能需求

### 2.1 卡片管理
- FR-1 新建/编辑/删除卡片（正面、背面、科目、标签）。
- FR-2 卡片分组、标记、错因与口诀。
- FR-3 卡片软删除与回收站。

### 2.2 复习调度
- FR-4 基于 FSRS-4.5 的间隔重复调度，按用户评分动态调整下次复习时间。
- FR-5 按到期队列复习，支持键盘快捷操作。
- FR-6 复习记录持久化，可回查历史。

### 2.3 AI 辅助
- FR-7 内容自动拆卡（AI 工具）。
- FR-8 基于薄弱点自动出题测验。
- FR-9 结合用户卡片的概念讲解（RAG）。
- FR-10 10 个领域智能体协作。

### 2.4 学习分析
- FR-11 掌握度/正确率/薄弱科目统计。
- FR-12 校准回测（Brier/ECE）。
- FR-13 到期洪峰预测。
- FR-14 模考成绩趋势与通过率预估。

### 2.5 单词英语
- FR-15 单词本：生词/熟词/词组/长难句分类。
- FR-16 单词间隔复习。

### 2.6 资料导入
- FR-17 支持 PDF / Word / 图片 OCR 提取文字。

### 2.7 跨设备同步
- FR-18 局域网中枢同步 / JSON 导入导出。
- FR-19 字段级合并、墓碑删除传播。

## 3. 非功能需求

| 类别 | 要求 |
|---|---|
| 可用性 | PWA，断网可复习已加载内容 |
| 性能 | 千张卡规模下检索秒级响应 |
| 安全 | 学习数据本地存储；AI Key 存 localStorage；Markdown 渲染经 DOMPurify |
| 可维护性 | 1079 项自动化测试、ESLint、i18n 闸门 |
| 兼容 | 现代浏览器（Chrome/Edge/Firefox/Safari），手机与平板自适应 |

## 4. 约束与假设
- 纯前端，无应用服务器；AI 调用由用户自备 API Key。
- 多端协同以局域网/手动备份为主，不提供云账号服务。

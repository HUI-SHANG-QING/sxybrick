## 三、"必要 / 非必要"分级说明

按用途，这套文档分三档，你按需取用：

**A. 答辩/登记必须要有（必要）**
- 根目录 `README.md`、`09-毕业设计/` 全套、`06-软件著作权/`、`02-技术文档/` 核心几份。

**B. 锦上添花（有更好，没有也能交）**
- `04-甲方交付/`、`05-公司开发/`、`03-使用文档/`。

**C. 对外推广/商业用途（个人毕设用不到）**
- `08-宣传市场/`、`04` 里的验收报告。写了是为了"全套齐"，不影响答辩。

## 四、一句话项目事实（所有文档统一口径）

- **名称**：SxyBrick 记忆卡片（本地优先版，PWA）
- **版本**：v2.0.0
- **形态**：纯前端单页应用 + 局域网同步中枢，无后端服务器
- **技术栈**：Vue 3.5 / Vite 6 / Pinia / Element Plus / Dexie(IndexedDB) / ECharts / KaTeX
- **核心算法**：FSRS-4.5 间隔重复、向量混合检索(RAG)、知识图谱、错题归因
- **AI 层**：10 个领域智能体 + 工具注册协议 + 多 Agent 黑板协作
- **质量**：1079 项自动化测试全绿、ESLint 0 告警、生产构建通过
- **部署**：GitHub Pages 静态托管，可离线（PWA）

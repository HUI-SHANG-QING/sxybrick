# 市场与竞品分析

## 1. 市场背景

记忆卡片/间隔重复类产品已被验证（Anki 全球数千万用户、不背单词/墨墨等月活百万级）。近年两个趋势：
- **AI 原生**：用户希望 AI 自动做卡、出题、答疑，而非手动制作。
- **数据主权**：用户对学习数据被云端平台收集日益敏感，本地优先（local-first）产品回潮。

## 2. 主要竞品对比

| 产品 | 优点 | 不足 | SxyBrick 的差异 |
|---|---|---|---|
| Anki | 算法成熟、生态强 | UI 老旧、无 AI、英文为主 | 内置 AI 智能体、中文本地化、知识图谱 |
| 墨墨/不背单词 | 词库大、体验好 | 只做单词、需付费、云端 | 全科卡片、数据本地 |
| Notion/普通笔记 | 灵活 | 无复习调度 | 有真正的间隔重复算法 |
| 各类背题 App | 题库现成 | 固定题库、不个性化 | 用你自己的材料、算法个性化 |

## 3. 差异化定位

- **算法**：采用 FSRS（比 Anki 经典算法更新一代的可调度模型），并做了个性化权重训练与校准回测。
- **AI**：不只是聊天框，而是"能查你数据"的智能体 + RAG，回答基于你的真实卡片。
- **架构**：纯本地 PWA，零服务器成本，离线可用，数据不出本机。

## 4. 目标人群优先级

1. 考研自驱型学生（愿自己导资料、重效率）。
2. 技术敏感、反感云题库的用户。
3. 有跨设备复习需求的人。

## 5. 风险与边界

- 无官方题库，冷启动需用户自己建卡（已用冷启动模板与 AI 拆卡缓解）。
- AI 功能依赖用户自备 API Key，有使用门槛。
- 无云账号，多端协同靠局域网/手动同步。
